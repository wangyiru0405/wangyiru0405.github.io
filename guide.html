一、基本操作

  1. 打开仓库：github.com/wangyiru0405/wangyiru0405.github.io
  2. 点要改的文件 → 点右上角铅笔图标（Edit this file）
  3. 修改代码
  4. 点右上角 Commit changes... → 弹窗里再点绿色 Commit changes
  5. 等 5–10 分钟，打开网站按 Ctrl + F5 强制刷新

快捷编辑：在仓库页面按键盘 .（点号），会打开在线编辑器，改完点左侧 Source Control 提交。

新建文件：仓库根目录点 Add file → Create new file。文件名框里可以直接输入 photos/album-3.html，GitHub 会自动建文件夹。

二、改首页信息

文件：index.html

改名字、学校、邮箱

找到这一段：

<header class="hero">
  <h1>你好，我是王一如</h1>
  <p>南京大学新闻传播学院在读研究生 | 关注学术研究、摄影作品与新闻写作。</p>
  <p>我的邮箱：221810031@smail.nju.edu.cn</p>
  <p>
    <a href="https://github.com/wangyiru0405">GitHub</a>
  </p>
</header>

直接改里面的文字就行，标签不要动。

改顶部格言

找到：

<p class="nav-motto"><em>由艰难而致高远</em></p>

把「由艰难而致高远」换成你想写的句子，<em> 保证斜体。

改学术作品

找到学术作品卡片里的 <ul class="item-list">，一条论文就是一整块：

<li>
  <a href="papers/academic-paper-1.pdf" target="_blank">论文标题</a>
  <span class="item-meta">年份 · 期刊名</span>
</li>

加论文就复制这一块，粘在 </ul> 前面；删论文就整块删掉。

三、加新闻作品

新闻作品分六个分类，每类一个页面，都在 news/ 文件夹里：

  • news/data.html 数据新闻
  • news/investigative.html 调查性报道
  • news/documentary.html 纪实报道
  • news/factcheck.html 事实核查
  • news/video.html 视频新闻
  • news/commentary.html 新闻评论

加一条作品

打开对应的分类页，找到 <div class="work-grid">，在里面加一块：

<a class="work-card" href="稿件链接" target="_blank">
  <h3>作品标题</h3>
  <div class="work-meta">媒体名 · 日期</div>
</a>

粘在 </div> 前面。一行自动排一个。

四、加摄影集图集

摄影集分两层：总览页 + 每个图集详情页。

加一个新图集

  1. 建文件夹：Add file → Create new file，文件名 images/album-3/README.md，内容随便写，Commit
  2. 进 images/album-3 文件夹 → Add file → Upload files → 上传封面 cover.jpg 和照片 01.jpg、02.jpg……
  3. 新建详情页：Add file → Create new file，文件名 photos/album-3.html，复制 photos/album-1.html 的内容，改标题和图片路径
  4. 在 photography.html 里加一张卡片： 
    <a class="photo-card" href="photos/album-3.html"
   style="background-image:url('images/album-3/cover.jpg');">
  <div class="photo-overlay">
    <h3>图集标题</h3>
    <div class="work-meta">张数 · 年份</div>
  </div>
</a>

图集里加照片

打开 photos/album-3.html，在 <div class="album-grid"> 里加一块：

<a href="../images/album-3/07.jpg" target="_blank">
  <img src="../images/album-3/07.jpg" alt="照片7">
</a>

五、上传图片

  1. 先建好文件夹（见上）
  2. 进目标文件夹 → Add file → Upload files
  3. 把图片拖进去
  4. 点下方 Commit changes

图片太大的解决办法

GitHub 网页上传单文件限制约 25MB。超了会报错。

  • 推荐：用 TinyPNG 或 Squoosh 压缩后再传
  • 网页展示的图片压到 200KB 以下足够清晰
  • 大图可以转成 .webp 格式，体积更小

图片命名规则

  • 只用英文、数字、连字符：photo-01.jpg
  • 不要用中文、空格、特殊符号
  • 大小写要一致：Photo.jpg 和 photo.jpg 是两个文件

六、路径规则

这是最容易出错的地方。看你的 HTML 文件在哪一层：

在根目录的文件（index.html、photography.html、news.html）

想指向写
另一个根目录页面news.html
子文件夹的页面news/data.html
图片images/album-1/01.jpg
样式style.css

在子文件夹的文件（news/data.html、photos/album-1.html）

想指向写
根目录页面../index.html
同层其他页面data.html
图片../images/album-1/01.jpg
样式../style.css

口诀：子文件夹里的文件，往上找加 ../；根目录的文件不加。

七、常见问题

1. 改了没生效

  • 等 5–10 分钟，GitHub Pages 有构建延迟
  • 按 Ctrl + F5 强制刷新，或用无痕窗口
  • 确认已经点了 Commit changes

2. 链接点开 404

  • 检查文件名大小写是否完全一致
  • 检查路径 ../ 多了或少了
  • 用浏览器直接访问完整网址测试：https://wangyiru0405.github.io/具体路径
  • GitHub 上按 t 键搜索文件名，看它实际在哪

3. 图片不显示

  • 确认图片已经上传到对应文件夹
  • 确认 HTML 里的文件名和实际文件名一模一样
  • 检查路径：根目录写 images/...，子文件夹写 ../images/...

4. 上传图片失败

  • 图片超过 25MB → 压缩后再传
  • 文件名含中文或空格 → 改成英文数字

5. 想删掉一个页面

  • 打开文件 → 右上角垃圾桶图标 → Commit
  • 记得去别的页面删掉指向它的链接，否则会 404

6. 网页样式乱了

  • 检查 style.css 里有没有重复或冲突的规则
  • 确认 HTML 里的 class 名和 CSS 里的一致

7. 误删了文件想找回

仓库主页 → Commits → 找到删除前的那次提交 → 里面能看到文件内容，复制出来重建。

这个页面只有你自己知道地址，可以随时打开查。地址：wangyiru0405.github.io/guide.html
